# Capsule Manager

Save AI conversation context locally and transfer it between AI platforms.

## Setup

```bash
npm install
pip install websockets aiohttp
```

## Run

```bash
npm start
```

## First use

1. Open Settings → add your API key (Gemini free recommended)
2. Click "Open Browser" → browser opens with CDP enabled
3. Chat on any AI site (Claude, ChatGPT, Gemini, DeepSeek)
4. Click "Save Capsule" → context saved locally
5. Go to another AI → copy capsule → paste and continue
